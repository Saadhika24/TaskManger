# 🗂️ Task Manager App 

A simple and responsive Task Manager web application that allows users to manage tasks across different stages: Todo, In Progress, and Done. Built as part of an internship assignment with a focus on clean UI, authentication flow, and task management functionality.

---

## 🚀 Live Demo
👉 Frontend Live Link: https://task-flow-buddy-08.lovable.app

---

## 📌 Features

### 🔐 Authentication
- User Login functionality  
- User Registration functionality  
- Secure session handling via Supabase  

### 📝 Task Management
- Create new tasks  
- Update existing tasks  
- Delete tasks  
- Tasks organized into:
  - Todo  
  - In Progress  
  - Done  

### 🎨 UI/UX
- Clean and minimal interface  
- Fully responsive design (mobile + desktop)  
- Loading and error states handled properly  

---

## 🛠️ Tech Stack
- Frontend: Lovable  
- Backend: Supabase (PostgreSQL, Authentication, APIs)  
- Deployment: Lovable Hosting  

---

## ⚙️ Backend Details
No separate backend server deployed. Backend services are handled via Supabase integration within Lovable, including authentication, database storage, and API functionality.

---

## 📌 Assumptions & Decisions
- Used Supabase instead of a custom backend for faster development  
- Focused on UI simplicity and core functionality as per requirements  
- State management handled within the frontend application  
- Prioritized complete working application over complex architecture  

---

## ⚖️ Trade-offs
- No custom backend server implemented  
- Limited backend customization due to use of Supabase  
- Simplified architecture using platform-based development (Lovable)  

---

## 🎯 Key Learnings
- Building full-stack apps using Lovable  
- Implementing CRUD operations in real-world applications  
- Working with authentication and database services (Supabase)  
- Managing task workflows across multiple stages
